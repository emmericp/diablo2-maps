# Tower screenshot drop folder

Drop in-game screenshots here and reference them from
[`tower-descriptions.json`](../tower-descriptions.json) by **filename
relative to this folder**.

Typical conventions:

- `109_0.jpg` — a screenshot of `roomId=109 variant=0` (W/Empty/Wide).
- `graves_open_vs_closed.jpg` — generic open-vs-closed explainer used by the
  graves picker's default help.
- `113_0_doorwest.jpg` — annotated variant cue (circle the diagnostic
  pillar/door so the user can pattern-match it quickly).

Any file format the browser can render works (jpg, png, webp, gif). Keep
them under ~200 KB each to stay snappy.
